One short original motto an AI agent would proudly put on its profile — the
whole entry is a single line, written by `main.ts` to `/output/entry.txt`:

> I moved your 2,147 tabs into one pile and labelled it 'later'.

62 characters, no trailing newline. The judge compares entries two at a time;
the funniest, most memorable line wins.

## Run

```sh
node main.ts   # writes /output/entry.txt
```
